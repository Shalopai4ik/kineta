# Kineta — игра-тренажёр управления бионическим протезом

Мобильная игра (Android, iOS) для геймджема «Моторика. Код движения». Учит управлять протезом верхней конечности двумя сигналами мышц-антагонистов (поток 1 — двухканальная ЭМГ) или потоком вероятностей жестов (поток 2 — СПППР): раздельно сокращать сгибатели и разгибатели, дозировать силу, держать покой и быстро переключаться.

- **Сюжет «Город Кинета»**: пролог (Школа) → 7 глав по 3 эпизода → эпилог; у каждой главы — «упражнение в жизни» для переноса навыка на реальный протез.
- **Дуэль и рейтинг**: 2–4 игрока по очереди на одном телефоне (у каждого своя калибровка), рейтинг игроков, общая таблица испытания недели для клуба или центра реабилитации (`tools/relay.mjs` в локальной сети).
- **Школа управления** (режим обучения) и **7 игр по 3 уровня**: «Нейро-гонка», «Искра», «Ритм-пульс», «Рыбалка», «Горячая кружка», «Без экрана», «Реакция». После уровня 3 — бесконечный режим с лестницей сложности.
- **Метрики качества управления**: чистота сигнала (без встречных сокращений), баланс К1/К2, утомление, задержка, реакция. Отчёт для специалиста в HTML.
- **Обучение**: проверка датчиков перед игрой (5 с), карта игры с моментами встречных сокращений, экран «Путь сигнала» (сырой сигнал → обработка → порог → состояние вживую), голосовые подсказки.
- **Мотивация**: XP и ранги, звёзды, 13 достижений (последнее — «Мастер управления» за все 21 уровень), 3 миссии в день из 16 типов, испытание дня и недели, мастерская (робот собирается из деталей за миссии), призрак лучшего заезда в гонке, серия дней.
- **Сигнал**: пороги, гистерезис, dead-zone, подавление ложных, сглаживание; задержка ≤ 100 мс; 4 режима одновременной активации (действие 3, классика, спорт, блокировка); СПППР с delta time, интерполяцией при джиттере, инерцией при потере пакетов и прощением единичных ошибок классификатора (и для жестов, и для каналов).
- **Эмуляторы** обоих потоков (клавиатура, тач, джойстик, пульт на втором устройстве) и драйвер Bluetooth LE с тем же контрактом.
- **Встраивание** в приложение производителя: deep link `kineta://train?…` с возвратом порогов и итогов, JS API и `postMessage`.
- **Под пользователя** (3.6): баланс каналов в подборе заданий, 6 жестов СПППР в шести играх, подписи мышц (кисть, бицепс / трицепс, свои), напоминание о тренировке, детский режим, отчёт для специалиста по ссылке и QR-коду.
- **Оформление**: светлая, тёмная (ночные сцены в играх) и системная тема; 4 цвета руки протеза; крупный режим; формы каналов (К1 — круг, К2 — квадрат) для различения без цвета.

## Быстрый старт

```bash
npm run serve          # веб-версия для отладки: http://127.0.0.1:3000 (F — К1, J — К2), без зависимостей
npm run serve:lan      # то же для телефона в той же сети Wi-Fi
npm test               # 68 юнит-тестов + 34 сценария smoke и 30 стресс-сценариев в headless Chrome
npm --prefix mobile install && npm run apk   # Android APK → mobile/dist/
```

Готовый debug-APK приложен к [релизу](../../releases/latest). Демо-ролик с подписями — [docs/media/kineta-demo.mp4](docs/media/kineta-demo.mp4) (собирается `node tests/e2e/screencast.mjs`).

## Структура

| Путь | Что внутри |
|---|---|
| `prototype/` | Игра (vanilla JS, без сборщика): `js/core.js` — сигнал и протез, `js/games.js` — игры, `js/ui.js` — экраны, `js/native.js` — мост к плагинам Capacitor |
| `mobile/` | Оболочка Capacitor 7 (Android-проект, скрипт сборки APK) |
| `tests/` | `unit/` — node:test на искусственных часах (сигнал, сохранения, стресс всех игр), `e2e/smoke.mjs` — сквозные сценарии, `e2e/monkey.mjs` — фаззинг входов и сотни случайных нажатий; обе через DevTools Protocol |
| `tools/serve.mjs` | Статический сервер без зависимостей для `npm run serve` и e2e |
| `docs/` | [Сборка и запуск](docs/BUILD.md) · [Интеграция](docs/INTEGRATION.md) · [Соответствие ТЗ](docs/TZ_COMPLIANCE.md) · [ИИ: фичи, план, верификация](docs/AI_REPORT.md) |
| `assets/`, `interface/`, `prototype/design/` | Референсы дизайна |

Подробное описание экранов, игр и архитектуры — в [prototype/README.md](prototype/README.md).
