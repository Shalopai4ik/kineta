# Kineta — игра-тренажёр управления бионическим протезом

Мобильная игра (Android, iOS) для геймджема «Моторика. Код движения». Учит управлять протезом верхней конечности двумя сигналами мышц-антагонистов (поток 1 — двухканальная ЭМГ) или потоком вероятностей жестов (поток 2 — СПППР): раздельно сокращать сгибатели и разгибатели, дозировать силу, держать покой и быстро переключаться.

- **Школа управления** (режим обучения) и **6 игр по 3 уровня**: «Нейро-гонка», «Искра», «Ритм-пульс», «Рыбалка», «Горячая кружка», «Реакция».
- **Метрики качества управления**: чистота сигнала (без встречных сокращений), баланс К1/К2, утомление, задержка, реакция. Отчёт для специалиста в HTML.
- **Мотивация**: XP и ранги, звёзды, 12 достижений, 3 миссии в день из 15 типов, испытание дня, серия дней.
- **Сигнал**: пороги, гистерезис, dead-zone, подавление ложных, сглаживание; задержка ≤ 100 мс; СПППР с delta time, интерполяцией при джиттере, инерцией при потере пакетов и прощением ошибок классификатора.
- **Эмуляторы** обоих потоков (клавиатура, тач, пульт на втором устройстве) и драйвер Bluetooth LE с тем же контрактом.
- **Встраивание** в приложение производителя: deep link `kineta://train?…` с возвратом порогов и итогов, JS API и `postMessage`.

## Быстрый старт

```bash
npm run serve          # веб-версия для отладки: http://localhost:3000 (F — К1, J — К2)
npm test               # 27 юнит-тестов + 21 сценарий в headless Chrome
npm --prefix mobile install && npm run apk   # Android APK → mobile/dist/
```

Готовый debug-APK приложен к [релизу](../../releases/latest).
