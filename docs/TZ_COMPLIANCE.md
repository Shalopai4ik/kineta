## Поток 1 — двухканальная ЭМГ

| Требование | Статус | Где / как |
|---|---|---|
| На вход 4 значения: 2 амплитуды 0…255 и 2 порога (Q&A 6) | ✅ | Пакет `{timestamp_ms, emg:[a1,a2], thr:[t1,t2]}`: `Ctrl.pushEmg`, `EmgEmulator` |
| Используются оба канала, баланс без доминирования одного (Q&A 5, недостаток прошлых игр) | ✅ | С 3.6 игра сама выравнивает: при перекосе больше 60/40 за последние игры задания для слабого канала выпадают чаще (~65 %) в «Искре», «Ритме», «Без экрана», «Реакции». | В каждой игре оба канала (таблица ниже). Баланс К1/К2 считается в каждой игре (`Ctrl.balance`) и показывается в результате; при перекосе больше 72/28 игра даёт совет |
| Пороговый режим: К1 → действие 1, К2 → 2, К1+К2 → 3, покой → 4 | ✅ | 4 состояния `REST / CH1 / CH2 / BOTH` (`Ctrl.evaluate`) |
| Порог, время удержания, подавление ложных срабатываний, dead-zone | ✅ | Датчики → тонкая настройка: `deadzone`, `hyst`, `suppressMs`, `switchMs` |
| Пропорциональный режим: сглаживание, ограничение скачков, визуализация активации | ✅ | EMA (`smoothing`) + slew (`slew`); шкалы, графики, игровые индикаторы. Пропорционально управляются руль в «Гонке», высота в «Искре» и зона в «Рыбалке» |
| Ручная настройка порогов и чувствительности в игре (Q&A 7–8) | ✅ | Пороги тянутся на графике, чувствительность 1–20 у каждого датчика, профили «Мягко / Норма / Чётко», калибровка |
| Игровые пороги могут отличаться от порогов протеза (Q&A 7) | ✅ | Режим «Свои в игре / Из протеза». Ручная правка порога переводит игру на свои пороги, протез не меняется |
| Одновременная активация в разных режимах протеза (Q&A 10, митап 34) | ✅ | «Действие 3» (по ТЗ), «Классика» (первый сигнал держит), «Спорт» (второй перехватывает), **«Блокировка»** (с 3.4: пока обе мышцы выше порогов, протез и игра стоят, на экране — «Блокировка» и подсказка расслабить лишнюю мышцу; `getState().blocked`). Игры без «обе мышцы» подстраиваются: ноты «обе» уходят на К1/К2, шаг «обе» в школе пропускается, нитро скрыто |
| Задержка ≤ 100 мс | ✅ | Отсчёты 100 Гц; задержка от сырого превышения порога до состояния измеряется (`Ctrl.latency`) и выводится на «Датчиках». В 3.2 подавление ложных снижено до 30 мс («Норма», «Чётко») и 40 мс («Мягко»): 60–80 мс в профиле «Норма», не больше 100 мс во всех трёх профилях даже при сигнале на 5 % выше порога (тест `signal.test.mjs`). Импульсы короче 30 мс по-прежнему отсекаются |
| Эмулятор двух кнопок / слайдеров (клавиатура, мышь, джойстик) с порогами (ТЗ, митап 35) | ✅ | Джойстик (с 3.5, Gamepad API): LT / RT — К1 / К2 пропорционально нажатию, A / B — кнопками, крестовина — жесты СПППР. Клавиши F/J, панели с силой по высоте касания, настройки шума и наводки, пороги 0…255 на пульте |

## Поток 2 — СПППР

| Требование | Статус | Где / как |
|---|---|---|
| JSON `{timestamp_ms, dist:{7 жестов}}`, часы МК не синхронизированы | ✅ | `Ctrl.pushSpppr`: только разница между пакетами, повторы и откат времени отбрасываются |
| Delta time и интерполяция при джиттере 10…100+ мс | ✅ | Постоянная времени сглаживания — 0.6 от фактического интервала по часам МК (`pktDt`), без рывков при джиттере 10–110 мс (тест) |
| Поток 10 Гц, задержка ≤ 100 мс (Q&A 24), отклик 100–150 мс (митап 32) | ✅ | На 10 Гц от первого пакета жеста до состояния 130–150 мс: это интервал пакета (100 мс, нужен второй пакет для подтверждения) + 30 мс подавления ложных. На 20–50 мс — 40–100 мс (тест `signal.test.mjs`) |
| Softmax: плавное управление по долям (flexion − extension) | ✅ | Вероятности нормируются, вектор = flexion − extension (руль в «Гонке», зона в «Рыбалке») |
| Packet loss > 200 мс — гасить скорость, не зависать | ✅ | Экспоненциальное затухание τ = 180 мс |
| Потеря > 1–2 с — критическая, выход (Q&A 25) | ✅ | 1.5 с → `signal:lost`: выход из управления — игра на паузе «Сигнал потерян», кнопка «Продолжить» неактивна до восстановления связи, «Выйти» — в меню. До 1.5 с — инерция к покою (ТЗ: гасить скорость). То же для ЭМГ |
| Прощать единичные ошибки классификации (коадаптация, Q&A 26) | ✅ | Каналы (с 3.4): пакет, в котором сменился ведущий класс, учитывается с весом 0.3, полностью — только после подтверждения следующим пакетом; одиночный выброс «сгибание 0.93» не включает К1 (тест), прощённые ошибки считаются (`Ctrl.forgiven`). Жесты: устойчивый жест ≥ 2 пакетов и ≥ 120 мс (`Ctrl.stableGesture`) |
| Варианты 2 жеста + нейтраль и 6 жестов + нейтраль (Q&A 22) | ✅ | Датчики → «Словарь СПППР». На 6 жестах пронация — «обе мышцы» во всех играх; «Реакция» даёт сигналы «Супинация / Приведи / Отведи / Пронация», «Школа» — 4 дополнительных шага, «Без экрана» (с 3.4) — голосовые команды «Ладонь вверх / Приведи / Отведи» с уровня 2; с 3.6 — «Гонка» (супинация — гудок), «Искра» (супинация — купол), «Рыбалка» (приведение — прикормка): 6 из 8 игр |
| Эмулятор JSON с ошибками, потерями, джиттером | ✅ | `SppprEmulator` и пульт `emulator.html`: джиттер, потери, пачки потерь, ошибки классификатора, обрыв на 2.5 с |
| Режимы должны быть полностью рабочими (Q&A 23) | ✅ | Все 7 игр и школа проходят в ЭМГ и в СПППР (2 и 6 жестов): smoke-тест запускает каждую игру в обоих потоках |
