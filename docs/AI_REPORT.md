# Отчёт об использовании ИИ: перечень фич, план, верификация

ТЗ разрешает ИИ-инструменты при условии перечня фич, плана и отчёта о верификации критичных модулей. Код игры, эмуляторы, тесты и документация писались с помощью ИИ-ассистента Claude Code под постановку и контроль команды. Графика процедурная (canvas, SVG), сгенерированных изображений нет. ИИ не используется во время работы игры: нет облачных вызовов и нейросетей на устройстве.

## 2. План работ

1. **Контракт данных.** Форматы Потока 1 и Потока 2 по ТЗ и ответам на Q&A. Единая точка выбора источника `createSource()`, чтобы эмулятор заменялся драйвером МК одной строкой.
2. **Конвейер сигнала.** Нормализация → сглаживание → dead-zone → пороги с гистерезисом → подавление ложных → состояния → метрики. Затем сторож связи.
3. **Эмуляторы.** Встроенный эмулятор (клавиатура, тач), затем пульт на втором устройстве.
4. **Режим обучения и игры.** У каждой механики свой навык из ТЗ: изоляция, сила, длительность, реакция, переключение. Оба канала поровну.
5. **Мотивация и удержание.** Уровни, звёзды, миссии, достижения, прогресс, отдых по времени сеанса и по утомлению.
6. **Интеграция и мобильная сборка.** Deep link, возврат результата, Capacitor Android, документация.
7. **Верификация.** Автотесты в headless Chrome (раздел 3), просмотр скриншотов всех экранов, замеры задержки.

### 3.5 Найденные ИИ-ошибки и как их поймали

| Ошибка | Как обнаружена | Исправление |
|---|---|---|
| Bluetooth в APK не работал: во встроенном браузере Android нет Web Bluetooth, а драйвер протеза использовал только его | Ревью мобильной сборки | `js/native.js`: `navigator.bluetooth` поверх плагина BLE, тест с имитацией плагина |
| Экспорт JSON в APK: `<a download>` в WebView ничего не скачивает | Ревью мобильной сборки | Filesystem + Share |
| Профиль «Мягко» нарушал лимит задержки (120–140 мс) | Новый тест задержки по всем профилям | Параметры профиля пересчитаны |
| Пустая запись дня давала навык «Изоляция 0 %» у нового пользователя | Скриншот пустого прогресса в e2e | Дни без данных не учитываются |
| Скрипт правки документации обрезал этот отчёт после заголовка раздела 3 | Проверка длины файла после правки | Раздел восстановлен из исходного текста |
| Скрипт правки кода превратил `$$(` в `$(`: `String.replace` трактует `$$` в строке замены как `$`, поэтому панель эмулятора падала при старте | Автотест: исключение `forEach of null` и FAIL всех проверок сигнала | Вызовы восстановлены, дальше замены только функцией `() => text` |
| Ссылки на `window.SPN` и `window.Host`: глобальные `const` не попадают в `window` | Ревью кода перед прогоном | Прямые ссылки на глобальные константы |
| Баланс К1/К2 не считался в «Искре» (короткие импульсы < 1.5 с) | Автотест: в результате не было строки «Баланс» | При малом времени баланс считается по числу активаций |
| Легенда «Реакции» на 7 сигналов налезала сама на себя | Визуальная проверка скриншота | Легенда разбивается на ряды |
| PowerShell-скрипт сборки без BOM ломался на кириллице | Запуск сборки | Файл сохранён в UTF-8 с BOM |

## 4. Чек-лист перед защитой (ручная проверка на телефоне)

1. Установить APK, открыть, пройти онбординг. Иконка и заставка — Kineta. Прогресс пустой, без плашки «Демо-данные».
2. Пройти «Школу» с мобильного эмулятора (кнопка «Эмулятор мышц» внизу).
3. Сыграть по уровню в каждую игру. Проверить книжную и альбомную ориентацию.
4. Включить голосовые подсказки (Профиль) и пройти «Горячую кружку»: голос по-русски, вибрация на ошибке.
5. Прогресс → «Отчёт для специалиста» и Профиль → «Экспорт»: открывается меню «Поделиться», файл открывается.
6. С реальным BLE-устройством (или nRF Connect в режиме периферии с сервисом 0xFFE0): «Мой протез» → профиль протокола → «Подключить», виден заряд и сигнал.
7. На «Датчиках» переключить поток, режим одновременной активации и словарь СПППР.
8. Запустить `node tools/relay.mjs` на ноутбуке, открыть пульт на втором телефоне и подключить его в игре. Экранные панели должны пропасть, управление — идти с пульта. Кнопкой «Обрыв 2.5 с» на пульте проверить паузу «Сигнал потерян».
9. `adb shell am start -a android.intent.action.VIEW -d "kineta://train?hand=right&thr1=110&thr2=70&return=https://example.org/done"`: интерфейс зеркальный, пороги 110/70, на результате есть кнопка «Вернуться».
10. Системная кнопка «Назад» закрывает шторку, ставит игру на паузу, возвращает на главную.

## 5. Сценарий скринкаста (5–7 мин)

1. Задача и аудитория, 30 с.
2. Онбординг → «Датчики»: поток ЭМГ 0…255 с порогами, пороги на графике, режимы одновременной активации, 1 мин.
3. «Школа управления», 1 мин.
4. Каждая игра по 30–40 с, акцент на том, как работают оба канала. «Горячая кружка» — отдельно: перенос в быт (пример организаторов с горячей кружкой).
5. Экран результата: точность, чистота, баланс, утомление → «Прогресс» → «Отчёт для специалиста».
6. СПППР на 6 жестах: «Реакция» с пульта на втором телефоне, обрыв связи, 1 мин.
7. Интеграция: deep link с порогами и возврат результата, 40 с.
